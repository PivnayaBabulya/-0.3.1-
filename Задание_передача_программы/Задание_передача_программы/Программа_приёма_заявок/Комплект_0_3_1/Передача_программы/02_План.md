# План работ

1. Распаковать архив, открыть Программа_приёма_заявок в VS Code.
2. Запустить исходную версию 0.3.0, снять начальное состояние.
3. Протестировать лимит заявок, сброс, смену статуса, дату приёма.
4. Зафиксировать расхождения с ТРЕБОВАНИЯ.txt.
5. Запустить исправленную версию 0.3.1, повторить тесты.
6. Заполнить документы 00–08 в папке Передача_программы.
7. Создать собственный README.md из шаблона.
8. Собрать комплект передачи Комплект_0_3_1 и проверить запуск.
