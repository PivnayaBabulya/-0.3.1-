# Риски

| Риск | Вероятность | Влияние | Мера |
| --- | --- | --- | --- |
| Python не установлен или не в PATH | средняя | запуск невозможен | установить Python 3, проверить python --version |
| Отсутствует logo.png | низкая | программа не запустится (PhotoImage) | держать logo.png рядом с app.py |
| Нет Tkinter | низкая | окно не откроется | установить Python с Tkinter |
| Ошибка в терминале | средняя | непонятен результат | сохранить текст терминала для отчёта |
| Неверная версия файла (0.3.0 вместо 0.3.1) | средняя | проверки не совпадут | сверять VERSION и заголовок окна |
