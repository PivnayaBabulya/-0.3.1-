# Дефект

## Краткое описание
1. Кнопка «Принять заявку» не блокируется на 10-й заявке — блокируется только на 11-й.
2. Кнопка «Сбросить» не обнуляет счётчик «Закрыто заявок» и не возвращает статус «Новая».

## Шаги воспроизведения
1. Запустить app.py версии 0.3.0.
2. Нажать «Принять заявку» 10 раз.
3. Нажать «Принять заявку» 11-й раз.
4. Нажать «Сменить статус» до «Готово» (закрыто = 1).
5. Нажать «Сбросить».

## Ожидаемый результат
- На 10-й заявке: надпись «Лимит: 10», кнопка заблокирована.
- После сброса: количество 0, дата —, закрыто 0, статус Новая.

## Фактический результат
- Блокировка только на 11-й заявке («Лимит: 11»).
- После сброса закрыто остаётся 1, статус остаётся «Готово».

## Причина
- В accept() проверка `if count > LIMIT` стоит после инкремента.
- В reset() не сбрасываются closed и status_index.

## Исправление в 0.3.1
- В accept() проверка `if count >= LIMIT` стоит до инкремента.
- В reset() сбрасываются closed и status_index, обновляются label_closed и label_status.
